ARISTO — Premium Men's Fashion E-Commerce Platform

Live Demo: aristo.com.bd

ARISTO is a full-stack e-commerce platform built for the Bangladeshi men's fashion market, featuring a complete customer shopping experience alongside a full-featured admin dashboard for store management.

✨ Features
Customer-Facing
🛍️ Product browsing with categories, collections (Summer, Winter, Eid, New Arrivals, Premium, Limited Edition)
🛒 Cart and wishlist with real-time global state sync
⚡ Time-aware flash sale pricing engine with automatic price reversion
⭐ Review system gated by delivery status
📦 Cash on Delivery checkout
🔔 In-app notifications with navbar bell (polling-based)
📧 Automated order confirmation emails and abandoned cart reminders
📱 Native mobile share (Web Share API) with desktop fallback (WhatsApp, Messenger, Facebook)
🔐 Secure authentication with session management (Supabase SSR)
👤 Customer dashboard — order history, address book (Bangladesh division/district support), reviews, notifications, security settings
Admin Dashboard
📊 Analytics with real period-based growth calculations (Recharts)
📋 Order management with expandable rows and inline status updates
👥 Customer management with profile/order history drawer and active/inactive toggle
🎟️ Coupon system with usage limits and per-user validation
🖼️ Banner management with Cloudinary integration
🔒 Role-based route protection via middleware
🛠️ Tech Stack
Layer	Technology
Framework	Next.js (App Router)
Language	TypeScript
Database & Auth	Supabase (Postgres, SSR Auth)
Styling	Tailwind CSS
Media	Cloudinary
Email	Resend
Charts	Recharts
Deployment	Vercel
🚀 Getting Started
Prerequisites
Node.js 18+
A Supabase project
